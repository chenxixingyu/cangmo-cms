# 仓墨功能清单与选择

本文件是**功能菜单**：你可以按编号勾选需要的模块，也可以直接选择「基础版 / 标准版 / 旗舰版」。

v1.0 默认交付下表中全部 **✅** 功能；**◇** 表示已实现但可按配置关闭或裁剪；**○** 表示 v1.0 不含、已列入路线图。  
当前建议：**旗舰版（全部 ✅ + 审计 + 备份 + API）**，适合个人博客、团队技术站与中小型内容站。

> 选择方式：回复形如 `A1 A2 A3 B1 B4 C2 ...`，或直接回复「旗舰版」「标准版」「基础版」。  
> 如果只想要最小系统，可选「基础版」，其余模块不注册路由、不加载模板即可。

## 推荐组合

### 基础版（最小博客）
`A1 A2 A4 A5 A6 A9 B1 B2 B6 B7 C1 C3 C4 C6 C7 C8 D1 D3 D8`
- 适合：个人随笔、内网文档。
- 不含：评论、媒体库、API、备份页面、审计。

### 标准版（推荐个人/团队）
`基础版 + A3 A7 A8 A10 A11 A12 A13 A14 B3 B4 B5 B8 B9 B10 C2 C5 C9 C10 C11 C13 D5 D6 D7 D9 D10 E1 E2`
- 适合：技术博客、团队内容站。
- 含：评论、媒体、API、备份、主题。

### 旗舰版（v1.0 默认，推荐）
`标准版 + C12 C16 C17 C18 D4 D11 E3(路线图)`
- 适合：对安全、审计、可运维性有要求的站点。
- 含：审计日志、完整安全基线、崩溃恢复、自检。

> 说明：v1.0 已实现全部 ✅ 项；若要「基础版/标准版」，可在 `WebApp` 路由注册处注释对应模块，或联系开发者做裁剪分支。  
> 由于本项目的目标是「一次性审核测试完成」，当前交付默认为**旗舰版全量**，避免二次裁剪造成回归风险。

## 与 Halo / WordPress 的差异

| 维度 | 仓墨 | 说明 |
| --- | --- | --- |
| 语言/运行时 | 仓颉原生 | 不依赖 JVM、PHP、Node 运行时 |
| 依赖 | 零第三方 Web 框架 | HTTP、模板、Markdown、JSON、存储均为原创 |
| 数据 | JSON 文档 + WAL | 无 MySQL/PostgreSQL 依赖，备份即文件 |
| 安全 | 默认严格 CSP + CSRF + 限流 | 不以插件方式补齐基础安全 |
| 扩展 | 主题目录 | 插件运行时在路线图中 |
| 规模 | 单机中小型站点 | 不建议百万级文章/高并发场景 |

## 已知边界（请在选型时确认）

1. **平台**：v1.0 面向 Windows x64（CNG `bcrypt.dll` 提供 PBKDF2 与 CSPRNG）。Linux 移植需要替换系统加密适配层。
2. **HTTPS**：进程内不做 TLS，生产环境请用 Caddy/Nginx 反代并设置 `CANGMO_COOKIE_SECURE=true`。
3. **搜索**：内存线性扫描，适合数千篇文章；十万级建议接入外部搜索引擎。
4. **媒体**：本地磁盘存储；对象存储为路线图。
5. **插件**：当前只有主题扩展，无动态插件运行时。
6. **多站点**：单实例单站点。
