# 仓墨 v1.0.0

首个完整版本：用**仓颉语言**从零构建的现代、安全博客 / CMS。

## 亮点

- **原生仓颉**：HTTP/1.1 服务器、路由、模板引擎、Markdown、JSON、WAL 存储、
  PBKDF2 密码哈希全部原创，不依赖第三方 Web 框架。
- **完整内容能力**：文章 / 页面 / 分类 / 标签 / 嵌套评论与审核 / 媒体库 /
  搜索 / 归档 / 定时发布 / 版本历史 / SEO / RSS / Sitemap / PWA。
- **安全默认**：CNG CSPRNG、PBKDF2-SHA256 12 万次、会话轮换、CSRF、严格 CSP、
  XSS 转义、上传魔数校验、路径穿越防护、登录/评论/API 限流、审计日志。
- **原创主题**：响应式、深色模式、无障碍、无第三方 CDN 资源。
- **可运维**：初始化向导、CLI、每日日志、JSON 备份/恢复、健康检查、调度线程。

## 运行

```powershell
$env:CANGJIE_HOME = "C:\Program Files (x86)\Cangjie"
$env:Path = "$env:CANGJIE_HOME\runtime\lib\windows_x86_64_cjnative;$env:CANGJIE_HOME\lib\windows_x86_64_cjnative;$env:CANGJIE_HOME\bin;$env:CANGJIE_HOME\tools\bin;$env:CANGJIE_HOME\tools\lib;$env:Path"
cjpm build
.\target\release\bin\main.exe serve
```

首次启动访问 `http://127.0.0.1:8080/setup`，使用控制台打印的 Setup token。

## 已知边界

- Windows x64（CNG `bcrypt.dll`）；Linux 需替换加密适配层
- 进程内无 TLS/HTTP2，生产建议 Caddy/Nginx 反向代理
- 搜索为内存线性扫描
- 暂无插件运行时、SMTP、TOTP、对象存储、多站点
