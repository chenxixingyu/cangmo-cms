# 仓墨 v2.0.2

新增 Stripe Checkout 会员开通。

## Stripe

- 后台「会员 → Stripe」配置：
  - Secret Key
  - Webhook Secret
  - API Base（默认 `https://api.stripe.com`）
- 会员页列出计划，登录用户点击「使用 Stripe 开通」：
  - 创建 Checkout Session（`mode=payment`，30 天）
  - 元数据：`email/plan_id/site_id/days`
  - 跳转 Stripe Checkout
- Webhook：`POST /webhooks/stripe`
  - 校验 `Stripe-Signature`
  - HMAC-SHA256 + 300 秒时间容差
  - `checkout.session.completed` 自动开通 30 天会员

## 边界

- 一次性支付，不是 Stripe Subscription；
- 没有退款、发票、续费失败处理；
- 没有价格 ID/优惠码/税费；
- Secret 与 Webhook Secret 明文存于 settings；
- 需要公网 HTTPS 才能接真实 Stripe；
- 没有管理端支付记录页（只有会员记录）。
