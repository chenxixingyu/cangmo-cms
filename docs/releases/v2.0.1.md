# 仓墨 v2.0.1

新增 HTTP 邮件 Provider 投递。

## 邮件投递

- 后台「工具 → 发件箱」配置：
  - Provider URL（HTTPS JSON 接口）
  - 发件人
  - API Key
- 点击「保存并投递待发邮件」后：
  - 读取 `data/mail-outbox/*.eml`
  - POST JSON：`from / to / subject / text`
  - 成功后标记 `X-Cangmo-Status: sent`
  - 失败标记 `failed`
- 适用于 Resend、Mailgun 等兼容 JSON 的接口（按 Provider 字段调整需改适配器）。

## 边界

- 没有 SMTP/TLS 客户端；
- 没有自动重试、退信、打开率；
- API Key 以明文存在 settings；
- 发送是后台手动触发，不是队列 worker；
- Provider JSON 结构固定为 `from/to/subject/text`。

## 验证

- 26 单元 + 236 基线 + 42 定向 = **304 项**。
- Mock Provider 收到 `Bearer` 请求与正确主题/正文。
