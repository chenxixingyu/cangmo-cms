# 仓墨 v1.2.1

安全、运维与媒体增强。

## API Token

- 创建令牌时可选择权限：`admin`、`posts.write`、`comments.write`、`media.write`。
- 支持有效天数与允许 IP；列表展示范围、过期时间、最后使用 IP。
- 文章、评论、媒体 API 写入按 scope 校验；越权返回 403。
- 旧令牌没有 scopes 时保持全权限兼容，页面上标记为「旧令牌」。

## 自动备份与加密

- 备份中心新增自动备份开关、间隔（小时）、保留份数、加密开关。
- 调度器按周期创建 `auto-*`，只清理自动备份；手动备份不自动删除。
- 加密格式 `CMB1`：
  - PBKDF2-SHA256 派生 64 字节密钥；
  - HMAC-SHA256 计数器流加密；
  - HMAC-SHA256 认证标签；
  - 口令只来自环境变量 `CANGMO_BACKUP_PASSPHRASE`，不落库。
- 加密备份下载/恢复时由服务端解密；未配置口令时拒绝。

## 媒体

- 替换文件：保持 URL 与媒体 ID，更新大小、哈希、尺寸与显示名。
- 批量删除：多选/全选；被引用附件跳过并统计。
- 缩略图：浏览器 Canvas 生成 480px WebP 变体，列表使用缩略图；浏览器不支持时保留原图。
- 无外部 ImageMagick/ffmpeg 依赖。

## 用户批量

- 用户列表多选，批量停用/启用。
- 最后一个管理员、当前用户等限制沿用原有校验。

## 搜索

- 内存倒排索引：中文单字/双字、ASCII 词，标题/摘要/正文/标签统一建索引。
- 以 WAL 代际做缓存失效；查询 token 缺失时回退线性扫描。
- 保留关键词高亮。
