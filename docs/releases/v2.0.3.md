# 仓墨 v2.0.3

Stripe Checkout 从一次性支付升级为订阅模式。

## 订阅

- Checkout `mode=subscription`。
- 计划 interval（month/year）映射为 Stripe recurring interval。
- 元数据仍包含 `email/plan_id/site_id/days`。
- Webhook：
  - `checkout.session.completed`：创建会员并保存 `subscription/customer`。
  - `invoice.paid`：按订阅 ID 延长 30 天。
  - `customer.subscription.deleted`：撤销会员。
- 签名校验：HMAC-SHA256 + 300 秒容差。

## 边界

- 续费按 30 天固定延长，不读取 Stripe `current_period_end`；
- 年付续费也按 30 天延长（需后续修正为 365）；
- 没有退款/发票/税费/优惠码；
- 没有订阅升级/降级/暂停；
- 需要公网 HTTPS 与真实 Stripe 账户。

## 验证

- 26 单元 + 236 基线 + 47 定向 = **309 项**。
- Mock Stripe：Checkout、checkout completed、invoice.paid 延长、subscription.deleted 撤销。
