# 仓墨 v1.6.0

账户、内容工作流、主题与运维增强（v1.4–v1.6 合并发布）。

## v1.4 账户闭环

- TOTP（SHA256、30 秒）+ 8 枚一次性恢复码，登录二次验证。
- API 读 scope（posts/comments/media）与每 Token 限流。
- 草稿预览分享：24 小时、noindex、可撤销。
- 审计按操作者/动作/日期/关键词筛选，CSV 导出。
- 登录设备列表与单会话撤销。
- 密码重置：30 分钟单次 token，重置后撤销全部会话。
- 评论通知与密码重置邮件进入 `.eml` 发件箱，可由 sendmail/worker 转发。

## v1.5 内容与主题

- 编辑审核流：待审核、通过、退回草稿。
- 内容日历：按月查看定时内容。
- 主题选项：`theme.json` 定义颜色/字号/宽度/圆角，按主题保存。
- 主题 JSON 包安装、覆盖前备份、一键回滚。
- 媒体文件夹、按文件夹筛选、媒体去重（同名+同哈希）。
- OpenAPI 3：`/api/v1/openapi.json`。
- Webhook：文章发布/新评论/测试事件，curl 投递，HMAC-SHA256 签名。

## v1.6 运维

- Dockerfile、docker-compose、systemd unit。
- `/metrics` Prometheus 文本指标，需 `CANGMO_METRICS_TOKEN`。
- 搜索分析：热门词、零结果次数。
- Webhook 失败重试队列：3 次、退避、后台重试/取消。
- 本地增量备份：按文档差异生成，支持链式恢复。

## 已知边界

- 邮件是发件箱队列，不内置 SMTP/TLS；需 sendmail 或外部 worker。
- 主题包只支持文本资源，不支持 zip/二进制图片。
- 服务端图片缩略图/WebP、对象存储、多站点、插件、完整 i18n 未实现。
- Webhook 通过 curl 投递，需系统安装 curl。
