# 仓墨 v2.0.0 生态基础版

本版本把仓墨从单站点 CMS 扩展为多站点、可扩展的生态基础版。

> **重要：本版本不包含 ActivityPub / 联邦。** 真实 SMTP、支付 Provider、对象存储、插件沙箱仍依赖外部服务或后续版本。

## 多站点

- 站点注册表与默认站点迁移。
- Host 解析、后台站点切换器。
- 文章、评论、媒体、分类、标签按站点隔离。
- 站点级主题、标题、描述、关键词、页脚。

## 扩展

- 领域事件总线。
- Sidecar 插件协议：HTTP 事件、能力声明、HMAC 签名、失败重试队列。
- 主题市场：JSON 索引、远程包、sha256、HMAC 市场签名。
- 主题包安装/备份/回滚。

## 身份与会员

- OAuth/OIDC 登录：授权码、state、UserInfo、按邮箱匹配本站用户。
- 会员计划、手工开通/撤销、文章公开/会员访问级别、服务端付费墙。

## Newsletter

- 按站点订阅者、双 opt-in、确认/退订 token。
- 活动草稿与发送到 `.eml` 发件箱。

## 运维

- Dockerfile / compose / systemd。
- `/metrics`、搜索分析。
- Webhook 与插件失败任务进入统一重试队列。

## 已知边界

- **ActivityPub/WebFinger/HTTP Signatures 未实现**，不能声称联邦支持。
- 邮件只写发件箱，没有 SMTP/API 投递。
- 会员没有支付 Provider，只能手工开通。
- OAuth 没有 PKCE，也没有校验 `id_token` 签名。
- 主题市场签名是 HMAC（市场密钥），不是作者 Ed25519 身份签名。
- 插件是外部 HTTP 进程，没有沙箱、自动启动、权限强制。
- 任务队列覆盖 Webhook/插件重试，不是通用邮件/联邦 worker。
