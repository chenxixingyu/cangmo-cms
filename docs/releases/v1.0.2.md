# 仓墨 v1.0.2

维护版本：中文 URL、封面校验、测试稳定性与仓库清理。

## 修复

- **中文 URL**：分类/标签自动 slug 不再使用无意义的 `item`，改为 `category-<hash>` / `tag-<hash>`；中文文章标题无别名时使用 `p-<hash>`。
- **封面校验**：文章封面只接受附件库 `/media/` 或 http(s) 地址，拒绝 `javascript:` 等危险协议。
- **测试稳定性**：定时发布测试改为轮询最多 36 秒，避免 20 秒调度周期造成的偶发失败。
- **筛选栏布局**：用户与评论筛选栏在宽屏下保持单行。

## 清理

- 删除未引用的 `tests/adminflow.mjs`。
- 删除重复的 v1.0.0 测试报告，保留 v1.0.1 正式报告。
- 删除未使用的 `jsonArrayFromTitles`、`PostService.categoryName`。

## 验证

- 21 个单元测试 + 138 项集成/安全断言 = **159 项**
- 13 项浏览器交互审计（封面附件库、分类内联创建、标签 Chip、附件灯箱、评论全选、头像选择器）
- Windows + Ubuntu CI 构建与单元测试
- 详见 [docs/TESTING.md](https://github.com/chenxixingyu/cangmo-cms/blob/main/docs/TESTING.md)

## 升级提示

从 v1.0.1 升级只需替换程序文件，保留 `data/`；无需迁移数据。新创建的中文内容会获得新的 hash slug，旧内容 slug 不变。
