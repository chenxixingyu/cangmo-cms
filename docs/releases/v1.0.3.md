# 仓墨 v1.0.3

上传修复与后台紧凑布局。

## 修复

- **浏览器上传**：修复 multipart boundary 被错误转小写导致的「multipart 数据损坏」。Chromium 的 `----WebKitFormBoundaryAbCd...` 现在可正常上传。
- multipart/CSRF 表单解析异常改为后台错误页，不再输出纯文本。
- 新增混合大小写 boundary 的回归断言。

## 布局

- 备份中心：移除两块大表单，改为「新建备份」「从文件恢复」按钮 + 对话框；备份列表全宽展示。
- 文章封面：16:9 大预览改为 96×54 缩略图，上传/附件库/链接收纳到「选择封面」菜单。
- 设置：站点信息、外观、评论改为可折叠菜单，默认只展开站点信息。
- 侧栏移除「分类」入口；分类仍在文章编辑器中创建和选择。
- 精简备份、设置、封面提示文案。

## 验证

- 21 个单元测试 + 139 项集成/安全断言 = **160 项**
- 13 项浏览器交互审计 + 14 项布局审计
- Windows + Ubuntu CI 构建与单元测试

详见 [docs/TESTING.md](https://github.com/chenxixingyu/cangmo-cms/blob/main/docs/TESTING.md)。
