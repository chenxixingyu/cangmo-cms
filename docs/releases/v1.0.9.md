# 仓墨 v1.0.9

后台脚本缓存与页面路径修复。

## 根因

- 后台 CSS 带 `?v={{ version }}`，但 `admin.js` 没有版本参数。
- 升级后浏览器继续执行旧 JS：旧 JS 不会给行菜单计算位置，新 CSS 又把菜单设为 `fixed`，于是菜单出现在视口左上角。
- 页面真实地址是 `/pages/<slug>`，但后台列表显示 `/slug`；演示导航使用 `/about`，因此访问 404。

## 修复

### 脚本缓存
- `foot.html` 的 `admin.js` 增加 `?v={{ version }}`。
- 升级后强制加载匹配版本，行菜单定位逻辑立即生效。
- 行菜单增加无 JS 回退：JS 未加载时贴近按钮展示，不再跑到左上角。

### 页面路径
- 后台列表显示真实路径：
  - 文章：`/posts/<slug>`
  - 页面：`/pages/<slug>`
- 新增根级兼容路由：`/about` 等已发布页面 301 跳转到 `/pages/about`。
- 未命中路径仍返回 404，不影响静态资源、后台与 API 路由。

## 验证

- 21 个单元测试 + 156 项集成/安全断言 = **177 项**
- 15 项 v1.0.9 浏览器审计：
  - 脚本版本参数
  - 行菜单定位、锚点、视口避让、行高不变
  - 页面抽屉与编辑器抽屉贴右、全高
  - `/about` → `/pages/about` 301
  - 列表显示真实路径
  - 侧栏无「系统管理」
- Windows + Ubuntu CI
