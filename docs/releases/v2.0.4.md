# 仓墨 v2.0.4

新增 Stripe Billing Portal 入口。

## Billing Portal

- 已订阅且保存了 `stripe_customer_id` 的会员，在会员页看到「管理订阅 / 发票」。
- 服务端创建 Stripe Billing Portal Session：
  - `customer`
  - `return_url`
- 重定向到 Stripe Portal，可管理支付方式、发票、取消订阅。

## 边界

- Portal 里的取消/变更通过 Stripe Webhook 回传；当前只处理 `customer.subscription.deleted`。
- 没有本地发票列表/退款操作；
- 没有 Portal 配置管理；
- 需要真实 Stripe Customer 与公网 HTTPS。

- 26 单元 + 236 基线 + 48 定向 = **310 项**。
- Mock Stripe：Portal Session 创建与跳转通过。
