# 仓墨 v1.3.0

设置与主题完善。

## 设置

- **站点**：标题、副标题、描述、关键词、地址、Logo、站点图标、页脚文字、版权、备案号、每页文章数、维护模式。
- **首页**：主标题、副标题、主图、精选文章开关。
- **外观**：主题色、颜色模式、正文字号、内容宽度、圆角、导航菜单、社交链接、自定义 CSS。
- **阅读**：目录、阅读时间、相关文章、列表作者/日期/分类/标签、摘要长度、相关文章数。
- **SEO**：默认分享图、Twitter/X 账号。
- **评论**：开关、审核、链接数限制。

设置页现在有六个标签，支持 `#appearance` 等 hash 直达。

## 主题

- 主题页显示当前主题、站点预览入口和「外观设置」。
- 默认主题支持：
  - Logo / 站点图标；
  - 首页主图与主标题；
  - 版权与备案号；
  - 列表元信息显隐；
  - `--wrap`、`--radius`、`--font-size` 变量；
  - 自定义 CSS。
- 自定义 CSS 通过 `/custom.css` 外部加载，不直接拼进 HTML，避免 `</style>` 注入。

## 维护模式

- 开启后访客访问公开页面返回 503 与维护提示。
- 管理员仍可访问后台与站点。
- `/healthz` 始终可用，便于探活。
