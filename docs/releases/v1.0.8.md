# 仓墨 v1.0.8

行操作菜单浮层修复与侧栏简化。

## 修复

- 「更多 / 操作」菜单不再在表格行内展开，不会撑高行高或挤压列表。
- 改为 `position: fixed` 视口浮层：
  - 按触发按钮定位，右对齐；
  - 自动避让视口边缘；
  - 底部行菜单自动向上翻转；
  - 不被表格横向滚动容器裁切。
- 点击外部、页面滚动、窗口缩放自动关闭；浮层内部滚动不会误关。
- 菜单功能完整保留：查看前台、复制为草稿、下线、删除等。

## 布局

- 移除侧栏「系统管理」折叠组及「系统管理」文案。
- 设置、主题、审计日志、工具、备份直接展示，入口和权限不变。

## 验证

- 21 个单元测试 + 156 项集成/安全断言 = **177 项**
- 10 项 v1.0.8 浏览器审计
- Windows + Ubuntu CI
