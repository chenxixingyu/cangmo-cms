# 仓墨 v1.0.4

后台紧凑化与批量操作。

## 布局

- 侧栏移除「标签」入口；分类、标签管理统一收纳到文章页「管理 ▾」菜单。
- 「设置 / 主题 / 审计日志 / 工具 / 备份」折叠为「系统管理」组，导航更短。
- 文章列表行操作改为「编辑 + 更多 ▾」，收纳发布、下线、恢复、删除、查看前台。
- 评论、附件、用户、分类、标签的行操作统一改为「操作 ▾」弹出菜单。
- 分类页新建分类改为对话框；用户编辑表单收进行内菜单。
- 表格内菜单采用行内展开面板，避免被表格横向滚动裁切。

## 功能

- 文章列表新增批量操作：发布 / 移入回收站 / 恢复为草稿 / 永久删除。
- 支持全选、已选计数，批量栏按需显示。
- 新增 `POST /admin/posts/bulk`，单次最多 100 项，逐项校验权限。
- 分类/标签页保留原有 URL 和表单字段，兼容旧链接与自动化脚本。

## 修复

- 定时发布测试改为秒级时间戳 + 60s 轮询，修复分钟截断造成的偶发失败。
- 弹出菜单支持点击外部自动关闭。

## 验证

- 21 个单元测试 + 139 项集成/安全断言 = **160 项**
- 27 项浏览器交互 / 布局审计
- Windows + Ubuntu CI

详见 [docs/TESTING.md](https://github.com/chenxixingyu/cangmo-cms/blob/main/docs/TESTING.md)。
