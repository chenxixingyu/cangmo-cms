# 仓墨 v1.0.1

附件库、内容工作台与 Linux x64 适配版本。

## 后台体验

- **附件库**（原媒体库）：`/admin/attachments`，支持类型筛选、文件名搜索、统计、灯箱预览、复制链接、删除；旧 `/admin/media` 仍可用
- **封面三选一**：上传图片 / 从附件库选择 / 直接填链接，并实时预览
- **编辑器内分类**：新建分类后立即选中，不需要离开编辑页；标签改为 Chip 输入
- **文章界面**：摘要计数、阅读时间、Ctrl/⌘+S 保存、回收站入口、状态与封面展示
- **评论页**：Halo 风格状态统计、搜索、按文章筛选、全选与批量通过/垃圾/删除
- **用户页**：角色/状态/文章数统计、搜索筛选、头像与当前用户标识
- **个人资料**：合并到右上角用户菜单，支持头像（附件库或 URL）、简介与密码
- **工具 / 备份拆分**：独立备份中心支持创建、下载、从文件或现有备份恢复、删除；恢复后强制重新登录
- 移除前台“还没有文章。去后台写下第一篇吧”空状态块

## Linux x64

- Windows 继续使用 CNG（`bcrypt.dll`）
- Linux 使用 OpenSSL `PKCS5_PBKDF2_HMAC` + `getrandom(2)`
- `cjpm.toml` 按 target 配置链接选项
- `scripts/start.sh` / `scripts/test-all.sh`
- GitHub Actions 双平台（Windows + Ubuntu）构建与单元测试全部通过

Linux 依赖：

```bash
# Debian / Ubuntu
sudo apt-get install -y libssl-dev
# Fedora / RHEL
sudo dnf install -y openssl-devel
```

```bash
source /path/to/cangjie/envsetup.sh
cjpm build
./target/release/bin/main serve
```

## 升级提示

1. 先创建备份并下载；
2. 停止服务，替换程序文件，保留 `data/`；
3. 启动后运行 `cangmo doctor`；
4. 旧 `/admin/media` 链接会自动显示新的附件库；
5. Linux 首次构建需安装 OpenSSL 开发库。
