# 仓墨 v1.0.7

页面内联编辑面板补全字段。

## 变更

- 页面列表的微缩抽屉新增：
  - **路径**（URL 别名）
  - **分类**
  - **标签**
- 抽屉宽度从 480px 收窄到 **420px**，覆盖列表右侧更小区域，保留更多列表可见范围。
- `GET /admin/posts/:id/drawer` 返回 `category_id` 与 `tags`。
- `POST /admin/posts/:id/quick` 接收分类与标签字段。
- 页面保存仍遵循原有规则：页面本身不落分类/标签，字段仅与完整编辑器保持一致；未改动数据逻辑。
- 未新增「模板选择」：当前代码库没有页面模板字段，避免引入虚假配置。

## 保持不变

- 点击「编辑」不跳转路由、不重绘导航与列表。
- 抽屉顶部显示页面名称，底部固定「保存 / 取消」。
- 保存后抽屉关闭，列表标题、状态、日期、浏览数原位更新。
- 字段校验、CSRF、`canEdit` 权限与 `PostService.save` 逻辑完全复用。

## 验证

- 21 个单元测试 + 156 项集成/安全断言 = **177 项**
- 16 项 v1.0.7 浏览器审计
- Windows + Ubuntu CI

详见 [docs/TESTING.md](https://github.com/chenxixingyu/cangmo-cms/blob/main/docs/TESTING.md)。
