# 仓墨 v1.0.5

权限修复、文件名修复与内容工作流增强。

## 修复

### 定时发布越权（安全）
投稿者（contributor）原本可以提交 `status=scheduled` 且把定时时间设为过去，服务端会将其直接转为已发布，绕过发布权限。现在定时发布与直接发布一样要求 `canPublish` 权限，投稿者只能保存草稿。

### 中文文件名丢失
`sanitizeFilename` 把所有非 ASCII 字节替换为 `-`，上传 `测试 截图.png` 后显示为 `.png`。新增 `sanitizeDisplayName`：
- 保留中文等 UTF-8 显示名；
- 去除路径分隔符、控制字符，替换不安全 ASCII 标点；
- 磁盘文件名仍使用生成的 `media_xxx.ext`，不影响存储路径安全。

### 设置项向后兼容
新增的「显示相关文章」开关带有 `show_related_posts_present` 标记；旧表单或自动化脚本省略该字段时保留原值，不会被误关闭。

## 布局

- 编辑器右侧的 **SEO** 与 **历史版本** 改为折叠面板，默认收起，缩短页面。
- 折叠只影响展示，SEO 标题、描述、URL 别名等字段仍在表单内正常提交。

## 新增

- **复制为草稿**：文章行菜单新增「复制为草稿」，保留正文、分类、标签、封面、SEO 字段，标题追加「（副本）」，状态重置为草稿。
- `POST /admin/posts/:id/duplicate`：复用 `PostService.duplicate`，按 `canEdit` / `canCreate` 校验；分类或标签被删除时自动降级为空。
- **相关文章开关**：设置 → 外观 → 显示相关文章，默认开启，关闭后文章页不再渲染相关文章区块。
