# 仓墨 v1.2.0

内容体验增强（第一批）。

## 已完成

### 版本差异
- 历史版本对话框新增「对比当前」。
- 行级 LCS diff：`-` 旧内容、`+` 当前内容；超过 2000 行时跳过对比，避免页面卡顿。

### 页面模板
- 页面新增 `template` 字段。
- 主题 `templates/page-*.html` 自动出现在后台下拉框。
- 默认模板 `page.html`；新增 `page-wide.html` 宽屏模板。
- 旧页面无 template 时回退 `page.html`，无需迁移。

### 301 重定向
- 新增 `/admin/redirects`：手动创建/删除站内 301。
- 修改已发布内容的 slug 时自动记录：
  - `/posts/old` → `/posts/new`
  - `/pages/old` 与 `/old` → `/pages/new`
- 仅允许站内路径；拒绝外部 URL、`..`、`/admin`、`/api`、`/media`、`/static`。

### 搜索高亮
- 搜索结果标题/摘要中的关键词使用 `<mark>` 高亮，HTML 已转义。

### 命令面板
- 顶栏「搜索或跳转」或 Ctrl/⌘+K 打开。
- 支持跳转仪表盘、文章、页面、评论、附件、用户、设置、主题、审计、工具、重定向、导入、备份。

## 本版未包含

| 功能 | 原因 |
| --- | --- |
| API Token scopes/过期/IP | 需要重构 API 认证上下文与逐端点权限 |
| 自动备份 + 保留 + 加密 | 需要 scheduler 注入、设置面板与加密格式设计 |
| 图片缩略图/WebP | 仓颉标准库无图像编解码；需外置 ImageMagick/ffmpeg 或纯仓颉解码器 |
| 媒体/用户批量操作 | 需新增批量端点与行选择 UI；建议下一批与权限一起做 |
