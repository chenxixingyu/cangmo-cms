# 仓墨 v1.0.6

后台全页面布局与交互统一。

## 编辑器

- 移除右侧常驻发布侧栏，正文编辑区占满横向空间。
- 右上角保留单个「发布」按钮，点击打开右侧抽屉。
- 抽屉集中承载：发布状态、定时时间、摘要、封面、分类、标签、置顶/精选/允许评论、SEO 与别名、历史版本。
- 抽屉底部固定「取消 / 保存」，字段纵向紧凑排布。
- 所有字段、CSRF、校验与保存逻辑保持不变。

## 页面列表

- 「编辑」不再跳转路由，改为右侧微缩抽屉。
- 抽屉承载页面全部编辑字段：标题、状态、定时、正文、摘要、封面、别名、SEO 与评论开关。
- 保存通过 `POST /admin/posts/:id/quick` 原地返回更新后的行数据，列表标题、状态、日期与浏览数即时刷新，抽屉自动关闭。
- 主列表全程可见；无 JavaScript 时仍可直接进入完整编辑页。

## 附件库

- 压缩类型统计卡片的高度、字号与内边距。
- 精简上传区说明与右侧提示。
- 操作统一收敛到「操作 ▾」菜单。
- 收窄卡片留白与模块间距，提高单屏附件数量。

## 用户与权限

- 压缩角色统计卡片、页面说明、新建用户入口、筛选栏与表格行高。
- 用户操作继续使用「操作 ▾」菜单。

## 系统设置

- 取消折叠分组，改为顶部横向标签：站点信息 / 外观 / 评论。
- 同一时间仅显示当前标签内容，保存按钮固定可见。
- 所有标签字段仍在同一表单内，切换标签不会丢失输入。

## 验证

- 21 个单元测试 + 155 项集成/安全断言 = **176 项**
- 21 项 v1.0.6 浏览器交互审计
- Windows + Ubuntu CI

详见 [docs/TESTING.md](https://github.com/chenxixingyu/cangmo-cms/blob/main/docs/TESTING.md)。
