# 仓墨 v1.1.0

内容工作流完善：版本恢复、附件治理、Markdown 导入。

## 版本历史

- 保存时快照扩展为：标题、正文、摘要、状态、分类、标签、封面、置顶/精选、评论开关、SEO、定时时间。
- 编辑器历史版本可「查看」与「恢复」。
- 恢复规则：
  - 保留当前 slug，旧链接不失效；
  - 状态固定为草稿，避免旧快照直接发布；
  - 恢复前自动保存当前内容为新快照，可再次撤销；
  - 已删除的分类置空、标签跳过。
- 权限沿用 `canEdit`；跨文章 revision 返回 404。

## 附件治理

- 新增重命名：只改显示名，URL、磁盘文件名、扩展名不变。
- 新增引用检查：扫描文章/页面封面与正文中的附件 URL。
- 删除前显示引用列表；有引用时默认拒绝，确认后可强制删除。
- 修复权限缺口：后台上传/删除与 API 上传均要求 `media.manage`，contributor 无法再通过直接 POST 或 Token 上传/删除附件。
- 无权限用户不再看到上传区。

## Markdown 导入

- 工具 → Markdown 导入，支持多文件（最多 20 个、单文件 1MB）。
- 支持简单 front matter：title、slug、summary、tags、category、cover、pinned、featured、seo_title、seo_description。
- 默认导入为草稿；「导入后直接发布」仅对有 `post.publish` 的角色生效。
- 未提供标题时使用文件名；分类不存在时置空；slug 冲突自动追加后缀。
- 结果表逐文件显示成功/失败原因。

## 新接口

```text
GET  /admin/posts/:id/revisions/:rev
POST /admin/posts/:id/revisions/:rev/restore
POST /admin/attachments/:id/rename
GET  /admin/attachments/:id/usage
GET  /admin/import
POST /admin/import
POST /admin/attachments/:id/delete   (force=1 可选)
```
